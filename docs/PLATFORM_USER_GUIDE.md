# Platform Expansion - User Guide

## Payments
- Add payment methods (card, PayPal) in the Payments screen.
- View transaction history with amounts, currency, and status.
- Refund payments directly from the app.

## Delivery
- Place delivery orders with an address.
- Track orders in real time with driver location.
- View driver assignments and delivery status.

## Calendar
- View meal plans and events on a calendar.
- Create, edit, and delete events.
- Sync with Google Calendar.

## Notifications
- Receive push, email, and SMS notifications.
- Configure notification preferences per channel.
- Mark notifications as read.

## Analytics
- View user engagement and nutrition trend reports.
- Generate PDF reports for custom date ranges.

## ML Recommendations
- Get AI-powered recipe and meal recommendations.
- Personalize preferences (cuisine, dietary tags, spice level).

## Organizations (Multi-tenant)
- Create and manage organizations.
- Invite members with roles (member, admin).
- Switch between organization contexts.

## Webhooks
- Register webhook endpoints for external integrations.
- View delivery history and status.

## Search
- Search recipes, meal plans, and grocery items.
- Get autocomplete suggestions as you type.

## Rate Limiting
- API rate limits applied per user/IP.
- View remaining quota in rate-limit status endpoint.

## Admin
- Manage users and view system health.
- Monitor system statistics.

## Moderation
- Review flagged content in the moderation queue.
- Approve or reject content.

## Loyalty
- Earn points for actions (recipes created, meals logged).
- Redeem points for rewards.
- Track tier progression (bronze, silver, gold).

## Subscriptions
- Subscribe to premium plans.
- View invoices and billing history.
- Cancel subscription anytime.
